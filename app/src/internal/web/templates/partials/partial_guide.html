Brewery 101

How to take a batch from recipe to the pub, what roles mean, and what each section of Brewhouse is for.

How to deliver a batch

Follow these steps in order. Each step advances the batch status.

  1. Recipes — Create a batch and pick ingredients. Available stock is checked out; shortfalls go to a planning order. Status: created
  2. Schedule — Book a brew day and a fermentation tank. Status: scheduled
  3. Brewday — Record original gravity (OG) and brew volume, then mark brewday completed. Status: brewday
  4. Hygiene — Confirm cleaning is done for the batch (or use Hygiene done on Brewday). Status: hygiene done
  5. Delivery — Set final gravity (FG), delivery volume, beer net SEK/L, and multiplier. Live estimate shows tax (fixed) and net (= beer net × multiplier × liters). Click Calculate & ready. Status: ready for delivery
  6. Deliver — On Delivery, click Deliver to mark the batch as sent to the pub. Status: delivered

Admin mode

Admin accounts sign in as superuser. Economy, IAM, and Settings stay hidden until you elevate.

  • Where — Open the profile menu (avatar, top right) and use the Admin mode toggle. Only admin accounts see it.
  • On — Your session becomes admin; Economy, IAM, and Settings appear in the navigation.
  • Off — You return to superuser; admin-only pages are left and those nav sections hide again.

Roles

Access has two layers: the account role on the user (IAM → Users), and a brewery membership role per brewery (IAM → Breweries).

Account roles

  • user — Brewing, Inventory (view), and Hygiene for breweries you belong to: recipes, schedule, brewday, delivery, and wishlist shortfalls from recipes.
  • superuser — Same as user, plus create and edit shared inventory and purchase orders. Economy, IAM, and Settings stay hidden.
  • admin — Signs in as superuser. With Admin mode on, full access including Economy, IAM, and Settings.

Brewery membership roles

  • user — Member of that brewery; can work on its batches.
  • superuser — Member plus inventory management for the shared stock.
  • brewery_admin — Manages that brewery (contacts, logo, and members). Not a global admin, and not set as the account role in Users — only on membership.

Economy and Settings always require elevated admin (see Admin mode above). IAM → Breweries is also available to brewery managers for their brewery; Users stays admin-only.

What each page does

Brewing

  • Brewery 101 — This guide.
  • Recipes — Create and manage batches; inventory checkout and planning shortfalls.
  • Schedule — Book brew day and tank.
  • Brewday — Enter OG and brew volume; edit or revoke brewday.
  • Delivery — Price and deliver hygiene-done batches to the pub.

Inventory

  • Malt / Hops / Yeast / Misc — Shared stock. Cost price feeds batch cost.
  • Orders — Plan purchases, mark ordered, complete to receive stock.

Hygiene

  • Routines — Confirm brewday cleaning so the batch can go to delivery.

Tools

  • Calculators — ABV from SG, Swedish alcohol tax, DME/LME to raise gravity, and water to dilute to a target SG.

Economy (admin)

  • Tax rates — Swedish beer alcohol tax formula used on delivery.
  • Monthly deliveries — Delivered batches by month for declaration and invoicing (CSV export).

IAM

  • Users — Create and edit accounts and roles (admin).
  • Breweries — Breweries, contacts, logo, and memberships. Brewery managers can edit their brewery and upload a logo (max 300×300, 1 MB).

Settings (admin)

  • Brand — Logo and favicon.
  • Tanks — Fermentation tanks for scheduling.
  • Multipliers — Options that scale beer net SEK/L on delivery.
  • Beer net price — Default SEK/L prefilling the Delivery form.
  • Hygiene routines — Master checklist used when confirming hygiene.
